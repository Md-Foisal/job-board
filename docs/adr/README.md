# Architecture Decision Records

Each file here records one decision that shapes the product: the situation, what was decided, and
what it costs. The format follows Michael Nygard's
[Documenting Architecture Decisions](https://www.cognitect.com/blog/2011/11/15/documenting-architecture-decisions).

Records are numbered in order and never renumbered. When a decision changes, the old record stays,
is marked as superseded, and points to the new one.

| --- | --- | --- |

| [0002](0002-business-rules-in-action-classes.md) | Business rules in single-purpose action classes | Accepted |
| [0003](0003-apply-on-this-site-only.md) | Applications happen on this site, and are the only way a company sees a candidate | Accepted |
| [0004](0004-staff-review-new-employers-posts.md) | Staff review a new employer's job posts first | Accepted |
| [0005](0005-ai-is-optional-and-never-scores-candidates.md) | AI is optional and never scores candidates | Accepted |
| [0006](0006-utc-moments-and-plain-calendar-dates.md) | Moments in UTC, calendar dates as they are | Accepted |
| [0007](0007-pay-compared-within-one-currency.md) | Pay is compared only within one currency | Accepted |
